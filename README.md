## 🚀 Über das Projekt

HalDo AI OS 18 ist eine moderne Web-basierte Betriebssystem-Foundation.

Das Projekt dient als Grundlage für ein erweiterbares KI-Betriebssystem mit:

- KI-System
- Modulverwaltung
- App-System
- Sicherheitsverwaltung
- Datenverwaltung
- Dashboard
- Erweiterungen
